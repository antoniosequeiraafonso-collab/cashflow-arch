# Cashflow Arch

Webapp simples para registar despesas e entradas, com dashboard e gravação no Firebase Firestore.

## Versão 2

- Home focada em submissão de movimentos
- Dashboard separado com indicadores e gráficos simples
- Página de movimentos com tabela completa
- Categoria determina automaticamente se é despesa ou entrada
- Data mantém-se após submissão
